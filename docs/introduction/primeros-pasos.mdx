# Primeros pasos

Tuna permite gestionar la infraestructura y las máquinas virtuales desde un único panel.

## Crear un VPS

Para desplegar un nuevo VPS:

1. Selecciona la imagen del sistema operativo.
2. Selecciona los recursos del VPS.
3. Configura la red.
4. Confirma el despliegue.

Tuna asignará los recursos necesarios y desplegará la máquina virtual en uno de los Nodes disponibles.

## Gestionar un VPS

Una vez desplegado, un VPS puede ser administrado desde el panel.

Entre las operaciones disponibles se encuentran:

- Iniciar
- Detener
- Reiniciar
- Reinstalar
- Eliminar
- Acceder a la consola

También se puede consultar el estado y los recursos asignados al VPS.

## Nodes

Los Nodes proporcionan los recursos físicos utilizados por las máquinas virtuales.

Tuna distribuye los VPS entre los Nodes disponibles según los recursos requeridos y la capacidad disponible.
