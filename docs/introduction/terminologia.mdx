Esta página define los términos utilizados en la documentación de Tuna y establece su uso para mantener una terminología consistente.

| Término | Uso |
| --- | --- |
| **Tuna** | Nombre de la plataforma de gestión de infraestructura. |
| **VPS** | Máquina virtual asignada a un cliente. |
| **VM** | Abreviatura de _Virtual Machine_. Se utiliza para referirse técnicamente a una máquina virtual. |
| **Node** | Servidor físico que ejecuta máquinas virtuales. |
| **Control Plane** | Componente central encargado de gestionar la infraestructura. |
| **Node Agent** | Agente que se ejecuta en cada Node y ejecuta las operaciones solicitadas por el Control Plane. |
| **Image** | Plantilla utilizada para crear una nueva máquina virtual. |
| **Instance** | Identificador lógico de una máquina virtual dentro de Tuna. |
| **Resource** | Recurso asignado a una máquina virtual, como CPU, RAM, almacenamiento o red. |
| **Deployment** | Proceso mediante el cual se crea y configura una máquina virtual. |
| **Console** | Acceso a la consola de una máquina virtual. |
| **Network** | Red virtual utilizada para proporcionar conectividad a las máquinas virtuales. |
| **Storage** | Almacenamiento utilizado por las máquinas virtuales. |
| **Snapshot** | Copia del estado de un disco o máquina virtual en un momento determinado. |
| **Cluster** | Conjunto de Nodes gestionados como una misma infraestructura. |
